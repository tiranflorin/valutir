# Update README

Keep the project README accurate when a feature, route, or dependency changes.

1. Read the existing `README.md` and inspect the changed project files or configuration needed to verify the change.
2. Update the README with:
   - a concise description of what changed;
   - how to use a user-facing feature or route, when applicable;
   - any new dependency, including its purpose and relevant install or run step.
3. Follow the README's existing structure and writing style. If it has no suitable section, add the smallest clear section rather than duplicating information.
4. Remove or correct documentation made stale by the change. Do not document secrets, local environment values, or unverified behavior.
5. Review the final README for accuracy, concise wording, valid Markdown, and consistent headings.
